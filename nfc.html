NFC Editor

App · October 2026 · Claude Code

View on GitHub ↗

A native iPhone app for reading, writing, and editing NFC tags. It does what the usual tag apps do, including the parts they charge for, and it stays free.

What it does

  • Read. Hold a tag to the top of the phone and see the chip type, serial number, memory layout, the records on it, a page by page memory dump, whether a password is set, the scan counter, and the NXP signature.
  • Write. Text, links, contact cards, Wi-Fi networks, Bluetooth devices, locations, social profiles, and more. Several records on one tag, in any order. It shows the byte count before you tap, reads the tag back afterwards to confirm the write, and can lock the tag if you ask it to.
  • Tools. Erase, copy one tag to another, lock, edit memory one page at a time, set or remove a password, send raw commands, and write a saved dump back to a tag.
  • Saved tags and write profiles, searchable, and exportable as JSON.

Privacy

No accounts, no analytics, and nothing leaves the phone. It uses Apple's Core NFC and nothing else.

Worth knowing

iOS gives apps no way to read MIFARE Classic data blocks or to pretend to be a tag, so it does not do either. A Classic tag still shows its serial number. It is written in Swift and the source is on GitHub under the MIT license.
