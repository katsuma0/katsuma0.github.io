Silly Spaces

Project · September 2026 · Web dev

Open the site ↗

The website for Silly Spaces, a group that runs silly events in interesting places so people who might never meet have an excuse to break the ice. If the idea is silly, everyone is a newbie.

What I built

  • One page with upcoming events, members, a join form, a gallery of past events, and a FAQ. Upcoming events hide themselves once their date has passed.
  • The join form drops each sign-up into a Google Sheet, so there is no server to run.
  • A page per past event, built by a small Python script from a folder of photos and a short text file.
  • A hidden upload page for my phone. Pick the photos, it shrinks them, and it opens a pull request. A GitHub Action builds the event page, and merging it puts the event on the site.

How it is put together

Plain HTML, one stylesheet, and one script, with no framework.
