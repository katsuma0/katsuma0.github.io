how this works

The route comes from a Garmin inReach Mini 2 in the car, pinging a satellite every few minutes — it works where there is no cell signal at all. An hourly job folds those pings into one small JSON file per day in this site's repo, and this page draws whatever it finds, so the map runs an hour or so behind the car; the marker with the white ring is the latest ping. There is also a phone tracker page as a finer-grained backup recorder. Built with Claude Code, Leaflet, and OpenStreetMap tiles.
