Satellite AI

Project · October 2026 · Python

A way to ask an AI from somewhere with no cell signal, using the satellite texting already built into iPhones.

How it works

You type a question in the app. It gets compressed, encrypted, and sent as a satellite text to a relay phone back home. The relay has internet, so it decrypts the question, asks Claude for a short answer, encrypts that, and texts it back. You paste the reply into the app and read it. Satellite texts are short, so every character counts: a 74 character question goes out as 90, since encryption adds about 30 and compression wins some of that back.

Scores

Text "follow leafs" and the relay sends updates as the game goes: each goal and the final for hockey, each period for basketball and football. Scores are looked up, never written by the AI.

Worth knowing

It is a working mock, not a finished app. The message format, a relay that runs on a laptop, and a web version of the app that walks through the whole round trip all work. There is no iOS app yet, and the relay does not read messages on its own yet. The code is private for now.
